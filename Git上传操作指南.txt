Git 本地仓库推送至 GitHub 操作指南
=====================================

【前置准备】
1. 确保已安装 Git 并完成首次配置：
   git config --global user.name "你的用户名"
   git config --global user.email "你的邮箱"
2. 确保已在 GitHub 上创建了远程仓库（如 My-Algorithm-Practices）
3. 确保本地已配置 SSH Key 或使用 HTTPS 方式认证


【场景一】本地已有仓库（已有提交），关联远程仓库并推送
-----------------------------------------------------------

1. 检查当前远程仓库配置：
   git remote -v

2. 若 origin 不存在，添加远程仓库地址：
   git remote add origin git@github.com:用户名/仓库名.git

3. 若 origin 已存在但地址错误，修改地址：
   git remote set-url origin git@github.com:用户名/仓库名.git

4. 查看当前分支名：
   git branch

5. 将当前分支重命名为 main（若当前为 master 或其他名称）：
   git branch -M main

6. 推送并设置上游分支：
   git push -u origin main


【场景二】本地无任何提交，首次初始化并推送
-----------------------------------------------------------

1. 添加所有文件到暂存区：
   git add .

2. 查看暂存区状态，确认文件无误：
   git status

3. 创建首次提交：
   git commit -m "Initial commit"

4. 添加远程仓库（若未添加）：
   git remote add origin git@github.com:用户名/仓库名.git

5. 将当前分支重命名为 main：
   git branch -M main

6. 推送至 GitHub：
   git push -u origin main


【场景三】后续日常修改、提交与推送
-----------------------------------------------------------

1. 查看当前修改状态，了解哪些文件有变动：
   git status

2. 查看具体修改内容：
   git diff

3. 将所有修改添加到暂存区：
   git add .

   （若只想添加特定文件，使用：）
   git add 文件名1 文件名2

4. 提交修改并添加描述信息：
   git commit -m "本次修改的描述说明"

5. 推送到远程仓库：
   git push

    （首次推送后已设置上游分支，后续可直接 git push）


【场景四】分支管理
-----------------------------------------------------------

分支是两个独立开发线，可以并行修改代码互不影响，常用于功能开发或多人协作。

1. 查看所有本地分支（当前分支前有 * 标记）：
   git branch

2. 查看所有分支（含远程分支）：
   git branch -a

3. 创建新分支（基于当前分支创建，内容复制当前分支的代码）：
   git branch 新分支名

   示例：git branch feature-login

4. 切换到指定分支：
   git checkout 分支名

   示例：git checkout feature-login

5. 创建新分支并立即切换到该分支（一步到位，推荐）：
   git checkout -b 新分支名

   示例：git checkout -b feature-login

6. 合并指定分支到当前分支（先切换到目标分支再合并）：
   git checkout main
   git merge 源分支名

   （将 源分支名 的修改合并到 main 中）

7. 删除本地分支（已合并的分支）：
   git branch -d 分支名

8. 强制删除本地分支（未合并的分支）：
   git branch -D 分支名

9. 将新分支推送到远程仓库：
   git push -u origin 分支名

   （首次推送需 -u 设置上游，后续直接 git push）

10. 删除远程分支：
    git push origin --delete 分支名

11. 从远程拉取指定分支到本地并切换：
    git checkout -b 本地分支名 origin/远程分支名


【常用辅助命令】
-----------------------------------------------------------

- 查看提交历史：
  git log --oneline

- 查看远程仓库地址：
  git remote -v

- 查看当前分支：
  git branch

- 放弃工作区未暂存的修改：
  git checkout -- 文件名

- 撤销 git add 操作（取消暂存）：
  git reset HEAD 文件名

- 拉取远程最新代码（多人协作时）：
  git pull


【注意事项】
-----------------------------------------------------------

* 若使用 HTTPS 方式连接 GitHub，推送失败可能是凭据过期，需配置个人访问令牌（Personal Access Token）
* 远程仓库为空仓库时才能直接 push，若远程已有 README/LICENSE 等文件，需先 git pull 合并再推送
* 建议 .gitignore 文件中排除不必要的文件（如 node_modules/、*.exe、.env 等）
